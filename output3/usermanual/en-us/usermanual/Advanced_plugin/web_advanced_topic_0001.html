    • Advanced Settings

    • Configuring the DDNS
      The DDNS feature will update Internet IP which bound with registered domain name periodically. When the IP address of the WAN interface is changed, the gateway automatically updates the relation between the domain name and the IP address. Thus, users of the external network can obtain the WAN interface address of the gateway through the domain name.
    • Configuring the SNTP
      The Simple Network Time Protocol (SNTP) is network time synchronization function. It is used to update the time periodically from the network server so that the local time can remain the same as the network time.
    • Configuring the Storage Services
      With Storage Services, you can view, modify, add or delete the shared file(s) on the USB device.
    • Changing the Antenna Mode
      You can choose whether to use the external antenna.
    • Configuring the Static Route
      You can configure static routing. Static routing specifies a fixed routing path to neighboring destinations.
    • Configuring the DMS
      Digital Media Server (DMS) aims to interwork wire networks with wireless networks (Such wire and wireless networks contain personal PCs, consumer appliances, and mobile devices ) in an effort to build a seamless environment in which people can share and develop fresh data media and services. Before using this function, make sure that the storage devices are connected through the USB port.
