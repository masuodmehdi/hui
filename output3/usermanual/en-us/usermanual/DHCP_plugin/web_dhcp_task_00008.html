Obtaining the MAC address of the client in the Windows operating system (OS)

  1. Choose Start > Run, enter cmd, and then press Enter.
  2. The command window is displayed, enter ipconfig /all, and then press Enter.
  3. The MAC address of the client is displayed as the Physical Address.
