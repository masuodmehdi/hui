Aktivieren bzw. Deaktivieren der automatischen PIN-Verifizierung

Wenn der PIN-Schutz (Personal Identification Number) aktiviert ist, können Sie die automatische PIN-Verifizierung aktivieren bzw. deaktivieren. Wenn die Verifizierung aktiviert ist, wird die PIN gespeichert und das gibt die Verifizierung automatisch bei jedem Start weiter.
