PIN-Verwaltung

  • Aktivieren bzw. Deaktivieren der PIN-Verifizierung
    Wenn die PIN-Verifizierung (Personal Identification Number) aktiviert ist, müssen Sie beim Starten des die PIN eingeben. Wenn die PIN-Verifizierung deaktiviert ist, muss keine PIN eingegeben werden.
  • Ändern der PIN
    Wenn die PIN-Verifizierung (Personal Identification Number) aktiviert ist, können Sie die PIN ändern.
  • Überprüfen der PIN
    Wenn die PIN-Verifizierung (Personal Identification Number) aktiviert ist, müssen Sie die PIN bei jedem Start des eingeben,um die Gültigkeit der USIM zu überprüfen.
  • Aktivieren bzw. Deaktivieren der automatischen PIN-Verifizierung
    Wenn der PIN-Schutz (Personal Identification Number) aktiviert ist, können Sie die automatische PIN-Verifizierung aktivieren bzw. deaktivieren. Wenn die Verifizierung aktiviert ist, wird die PIN gespeichert und das gibt die Verifizierung automatisch bei jedem Start weiter.
