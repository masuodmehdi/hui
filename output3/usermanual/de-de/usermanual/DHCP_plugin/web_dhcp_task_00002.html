DHCP-Clients konfigurieren

Wenn der DHCP-Server (Dynamic Host Configuration Protocol) aktiviert ist, müssen einige Einstellungen Client-seitig konfiguriert werden. Als Beispiel für die Konfigurierung dient ein Windows XP Betriebssystem.

  1. Wählen Sie Start > Systemsteuerung > Netzwerkverbindungen > Drahtlose Netzwerkverbindung.
  2. Klicken Sie mit der rechten Maustaste auf das Symbol Netzwerkverbindung und wählen Sie Eigenschaften.
  3. Wählen Sie Internetprotokoll (TCP/IP) und klicken Sie auf Eigenschaften.
  4. Im Dialogfeld Eigenschaften Internetprotokoll (TCP/IP) wählen Sie IP-Adresse automatisch beziehen und DNS-Server-Adresse automatisch beziehen.
  5. Klicken Sie auf OK.
