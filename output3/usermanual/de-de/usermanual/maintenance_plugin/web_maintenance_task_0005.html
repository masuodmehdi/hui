Online-Aktualisierung

Nachdem Ihr mit dem Internet verbunden ist, können Sie diese Funktion verwenden, um das Upgradepaket vom Huawei Cloud-Server herunterzuladen, um Ihr aufzurüsten.

Voraussetzung

WARNUNG:

Stellen Sie sicher, dass das vor einer Aktualisierung mit dem Internet verbunden ist.

Vorgehensweise

  1. Klicken Sie auf > .
  2. Prüfen Sie, ob eine neue Version verfügbar ist.
  3. Wird eine neue Version gefunden, klicken Sie auf und starten Sie die Online-Aktualisierung. Eine Statusanzeige zeigt den Fortschritt der Aktualisierung an. Bitte warten Sie und schalten Sie den nicht aus.

    HINWEIS:

    Klicken Sie auf , falls Sie die Aktualisierung beenden wollen. Klicken Sie im angezeigten Dialogfeld auf und das Upgrade wird sofort abgebrochen.
