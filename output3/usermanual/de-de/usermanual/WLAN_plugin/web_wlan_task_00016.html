Konfigurieren der WLAN-Bridge

Mit der Funktion WLAN-Bridge können Sie zwei oder mehr Gateways verbinden, die ebenfalls die WLAN-Bridge-Funktion unterstützen, um gemeinsam ein größeres Netzwerk aufzubauen.

Vorgehensweise

  2. Wählen Sie aus dem Dropdown-Listenfeld eine Zugriffsmethode aus.
    • : Nur die Geräte erhalten Zugriff, die die MAC-Adresse des kennen.
    • : Die Funktion WLAN Bridge ist aktiviert.
    • : Die Funktion WLAN Bridge ist deaktiviert.
  3. Folgen Sie den Anweisungen auf der Seite, um die Parameter einzugeben.
    • : Bezieht sich auf die physikalische Adresse der Remote-Peer-Brücke. Das unterstützt den Point-to-Multipoint (PTM) Brückenmodus.
    • : Bezieht sich auf die Liste der physikalischen Adressen der Remote-Peer-Brücken.
    • : zeigt an, dass die konfiguriert wurde.
