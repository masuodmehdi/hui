Konfigurieren der Speicherdienste

Mit Speicherdienste können Sie freigegebene Dateien auf dem USB-Gerät anzeigen lassen, ändern, hinzufügen oder löschen.

Voraussetzung

Vor Durchführung stellen Sie bitte sicher, dass bereits ein USB-Gerät mit demverbunden ist.Daskann maximal 11 logische Partitionen erkennen.

Freigegebene Datei anzeigen

HINWEIS:
  • Bei dem folgenden Vorgang dient ein Computer mit Windows 7 Betriebssystem als Beispiel.
  • Bitte trennen Sie das USB-Gerät NICHT SOFORT vom, nachdem Sie Dateien hinzugefügt, geändert oder gelöscht haben, sondern warten Sie 5 Sekunden lang, damit die Änderungen übernommen werden.
  • Wenn Sie nach dem Hinzufügen, Ändern oder Löschen von Dateien keine Änderung am USB-Gerät erkennen können, sollten Sie den Ordner manuell aktualisieren (klicken Sie mit der rechten Maustaste in den leeren Ordner und wählen Sieaktualisieren), um zu sehen, welche Änderungen übernommen wurden.
  • Wenn Sie einen Computer mit Windows XP Betriebssystem verwenden, greifen Sie bitte über die IPv4-Adresse auf das USB-Gerät zu.Windows XP bietet keine optimale Unterstützung für IPv6, daher ist es möglich, dass Sie über die IPv6-Adresse nicht zugreifen können.

Die freigegebene Datei über den Samba anzeigen.

  1. Schalten Sie den PC ein.
  2. Verbinden Sie den PC über Ethernet oder WLAN mit dem.
  3. Wählen SieStart > Ausführen, geben Sie die IP-Adresse für dasein (Standard-IPv4-Adresse:\\192.168.1.1, Standard-IPv6-Adresse:\\fe80--1.ipv6-literal.net), drücken Sie anschließendEingabe.
  4. Geben Sie den Benutzernamen und das Passwort ein, die Sie auf der Seitekonfiguriert haben.
  5. Freigegebene Dateien anzeigen.

Freigegebene Datei über den FTP-Server anzeigen.

  1. Schalten Sie den PC ein.
  2. Verbinden Sie den PC über Ethernet oder WLAN mit dem.
  3. Starten Sie einen Webbrowser und geben Sieftp://192.168.1.1(IPv4) oderftp://[fe80::1](IPv6) ein, um sich auf der Verwaltungsseite anzumelden.
  4. Geben Sie den Benutzernamen und das Passwort ein, die Sie auf der Seitekonfiguriert haben.
  5. Freigegebene Dateien anzeigen.
