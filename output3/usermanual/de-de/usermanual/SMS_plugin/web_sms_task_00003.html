Nachrichten verwalten

Sie können sich empfangene und gesendete Nachrichten und Entwürfe ansehen.

Kontext

  • : speichert erhaltene Nachrichten.
  • : speichert gesendete Nachrichten, inklusive der Nachrichten, die erfolgreich versendet wurden und deren Versand fehlgeschlagen ist.
  • : speichert Entwürfe.

Vorgehensweise

Alle einblenden
  1. Wählen Sie > //.
  2. Von der angezeigten Seite aus können Sie

    • Umblättern und Nachrichten lesen.
    • Den Speicherstatus aktualisieren.
    • Nachrichten markieren oder Markierungen entfernen.
    • Markierte Nachrichten löschen.

  3. Klicken Sie auf eine Nachricht, um die Nachrichtendetails zu öffnen. Anschließend können Sie:

    • Die Nachricht beantworten.
    • Die Nachricht weiterleiten.
    • Die Nachricht löschen.
