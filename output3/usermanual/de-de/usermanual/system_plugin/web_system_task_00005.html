Ändern des Kennwortes

Ändern Sie das Anmeldungskennwort, um unbefugten Zugriff auf die Managementseite zu verhindern.

Vorgehensweise

  1. Wählen Sie > > .
  2. Geben Sie das aktuelle Kennwort ein.
  3. Geben Sie ein neues Kennwort ein und bestätigen Sie es.
  4. Klicken Sie auf .

    HINWEIS:

    Zum Schutz Ihres Kontos sollte Ihr neues Kennwort die Anweisungen auf der Managementseite erfüllen.
