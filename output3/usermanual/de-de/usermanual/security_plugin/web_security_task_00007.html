Konfigurieren von speziellen Anwendungen

Das unterstützt die Verwendung spezieller Anwendungen für die Konfiguration der dynamischen Portweiterleitung. Bestimmte Anwendungen im LAN-Netzwerk (Local Area Network) müssen einen bestimmten Port in der Firewall verwenden, um auf Remoteanwendungen zugreifen zu können. Um eine TCP- und eine UDP-Verbindung zwischen einer Anwendung im LAN und einer Remoteanwendung einzurichten, verwendet die Firewall diese Weiterleitungsfunktion, um den benötigten Port zu öffnen.

Beispiel für die Konfiguration einer speziellen Anwendung

Ein Client im LAN verwendet TCP, um über Port 47624 auf den MSN Gameserver zuzugreifen. Wenn das Spiel beginnt, verwendet der Gameserver TCP und Port 2400, um eine Verbindung mit dem Client herzustellen, der versucht, auf den Server zuzugreifen. In diesem Fall müssen Sie die dynamische Portweiterleitung konfigurieren, da das Spiel mit den folgenden standardmäßigen Firewallregeln in Konflikt steht:

  • Die Firewall blockiert die externe Dateneingabe.
  • Der Gameserver kann eine Verbindungsanforderung an die externe IP-Adresse des senden, kann aber diese Anforderung nicht an den LAN-Client senden, der versucht auf den Gameserver zuzugreifen, da die IP-Adressen des Clients nicht für externe Geräte offen sind.

Um dieses Problem zu lösen, müssen Sie einen Satz von Portweiterleitungsregeln festlegen. Wenn der Client im LAN Daten an den TCP-Port 47624 sendet, erlaubt die Regel die Dateneingabe von TCP-Port 2400. Dann können Daten des Gameservers empfangen und an den LAN-Client gesendet werden, der Daten an den TCP-Port 47624 sendet.
