Konfigurieren des virtuellen Servers

Das unterstützt einen virtuellen Server, damit externe Benutzer die Möglichkeit haben, die angebotenen Dienste im LAN-Netzwerk (Local Area Network) unter Verwendung des Hypertext Transfer-Protokoll (HTTP), File Transfer-Protokoll (FTP) und anderer Protokolle zu nutzen.

  3. Klicken Sie auf , damit die Einstellungen übernommen werden.

Konfiguration eines FTP-Servers

Zum Aktivieren der FTP-Dienste für einen Client mit der IP-Adresse 192.168.1.101 und der Möglichkeit des Zugriffs durch externe Benutzer gehen Sie folgendermaßen vor:

  3. Im Browser eines externen Benutzers geben Sie die FTP-Serveradresseftp://10.2.1.123ein und greifen auf den FTP-Dienst zu, den der Client mit der IP-Adresse 192.168.1.101 anbietet.
HINWEIS:

Standardmäßig ist der FTP-Dienstport 21. Wenn dieser Port geändert wird, zum Beispiel auf 8021, muss der externe Benutzer ftp://10.2.1.123:8021 eingeben, um auf den FTP-Server zugreifen zu können.
