  • Akronyme und Abkürzungen

    • Sicherheitseinstellungen

    • Aktivieren bzw. Deaktivieren des Firewall-Switch
      Das unterstützt die Firewall-Funktion, um die Übertragung von Datenströmen zu kontrollieren und Ihr lokales Netzwerk vor nicht autorisiertem Zugriff zu schützen.
    • Konfigurieren des LAN-IP-Filters
      Die IP-Adressfilterfunktion im LAN-Netzwerk (Local Area Network) kann verwendet werden, um den Zugriff bestimmter Clients im LAN auf bestimmte Internetdienste zu beschränken.
    • Konfigurieren des LAN-MAC-Filters
      Sie können die Clients, die auf das WLAN zugreifen, steuern und verwalten und die WLAN-Sicherheit verbessern.
    • Konfigurieren des URL-Filters
      Wenn Sie das Kontrollkästchen für die URL-Filterung aktivieren, steuert das Gateway den Zugriff auf Websites.
    • Konfigurieren des virtuellen Servers
      Das unterstützt einen virtuellen Server, damit externe Benutzer die Möglichkeit haben, die angebotenen Dienste im LAN-Netzwerk (Local Area Network) unter Verwendung des Hypertext Transfer-Protokoll (HTTP), File Transfer-Protokoll (FTP) und anderer Protokolle zu nutzen.
    • Konfigurieren von speziellen Anwendungen
      Das unterstützt die Verwendung spezieller Anwendungen für die Konfiguration der dynamischen Portweiterleitung. Bestimmte Anwendungen im LAN-Netzwerk (Local Area Network) müssen einen bestimmten Port in der Firewall verwenden, um auf Remoteanwendungen zugreifen zu können. Um eine TCP- und eine UDP-Verbindung zwischen einer Anwendung im LAN und einer Remoteanwendung einzurichten, verwendet die Firewall diese Weiterleitungsfunktion, um den benötigten Port zu öffnen.
    • Konfigurieren des DMZ
      Wenn externe Benutzer nicht auf bestimmte Netzwerkdienste zugreifen können, welche vom LAN-Netzwerk zur Verfügung gestellt werden, verwenden Sie die DMZ-Funktion des , um die Clients, die die benötigten Netzwerkdienste anbieten, als DMZ-Host einzurichten. Externe Benutzer können anschließend auf diese Dienste zugreifen. DMZ steht für entmilitarisierte Zone (Demilitarized Zone) in Netzwerken.
    • SIP-ALG konfigurieren
      SIP (Session Initiation Protocol) ist ein Control-Protokoll auf Anwendungsebene. Es wird verwendet, um eine Sitzung zu initiieren, zu ändern oder zu beenden. Mit Application-Level Gateway (ALG), das auch als Firewall auf Anwendungsebene oder Proxy Firewall auf Anwendungsebene bezeichnet wird, wird das SIP stabiler und vollständig. Um eine SIP-Anwendung auszuführen, aktivieren Sie SIP-ALG.
    • UPnP konfigurieren
      Der Universal Plug and Play-Dienst (UPnP) ermöglicht eine intelligente Verbindung zwischen zwei UPnP-Geräten mittels Portweiterleitung. UPnP-Geräten kann automatisch eine IP-Adresse zugewiesen werden und sie können dynamisch auf das Internet zugreifen.
    • ACL konfigurieren
      Wenn Sie das Kontrollkästchen ACL (Access Control List) aktivieren, steuert das Gateway den Zugang aus dem LAN und dem WAN zum Gateway.
