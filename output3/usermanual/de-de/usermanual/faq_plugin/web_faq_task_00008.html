Wie füge ich einen Drücker hinzu?

HINWEIS:
  • Als Beispiel dient ein Computer mit dem Windows XP Betriebssystem.
  • Falls der externe USB-Drucker nicht verwendet werden kann, wenden Sie sich bitte an den Druckerhersteller, der Ihnen sagen kann, ob diese Methode unterstützt wird.

Einen Drucker über Samba hinzufügen

  1. Installieren Sie den Druckertreiber auf Ihrem PC und verbinden Sie anschließend den PC und das über Ethernet oder WiFi.
  2. Schließen Sie den Drücker über USB-Kabel an das an und schalten Sie beide ein.
  3. Melden Sie sich auf der Verwaltungsseite an und wählen Sie > > .
  4. Überprüfen Sie und klicken Sie auf .
  5. Klicken Sie auf , um die Parameter wie folgt zu konfigurieren.
    • /: Folgen Sie den Angaben auf der Seite, um den Benutzernamen und das Passwort einzugeben. Beim Zugriff auf Samba müssen Sie zum Anmelden diese Parameter eingeben.
    • : Wählen Sie oder .
    • : Klicken Sie auf und wählen Sie das Stammverzeichnis des Druckers.
  6. Wählen Sie Start > Ausführen, geben Sie die Standard-IP-Adresse ein für das : \\192.168.1.1, und drücken Sie anschließend auf die Eingabe.
  7. In dem angezeigten Dialogfeld geben Sie den Benutzernamen und das Passwort ein, die Sie auf der Seite für den Zugriff auf den Samba-Dienst konfiguriert haben.
  8. Doppelklicken Sie auf das Druckersymbol im Fenster. Folgen Sie den Anweisungen des Assistenten und wählen Sie den entsprechenden Druckertreiber aus, um einen Drucker hinzuzufügen. Warten Sie für einige Minuten, damit die Einstellungen übernommen werden.
